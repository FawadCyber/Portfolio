Amazon Buyer Message Fetching

A scheduled support-data pipeline that retrieves Amazon buyer emails from Gmail, parses message content, enriches the records through Odoo lookups, removes duplicates, and maintains a structured Google Sheet for the support team.

  • n8n
  • Gmail
  • Odoo
  • Google Sheets
  • JavaScript

System flow

  1. Run on schedule and retrieve matching Gmail messages
  2. Load each complete buyer message and normalize it in JavaScript
  3. Enrich the message through Odoo customer and record lookups
  4. Split and deduplicate the processed records
  5. Append or update the support tracking sheet

What this proves

  • Published n8n workflow shown end to end
  • Real buyer-message rows were verified in the destination Google Sheet
  • Buyer-identifying screenshots and the raw workflow export are intentionally kept out of the public site
