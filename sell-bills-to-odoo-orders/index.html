ERP automation / workflow build

Sell Bills → Odoo Sales Orders

A structured ERP migration workflow that iterates through source spreadsheet tabs, cleans each row, checks existing Odoo records and product attributes, applies JavaScript transformations and filters, then creates the required sales-order records.

  • Odoo
  • Google Sheets
  • JavaScript
  • Data Mapping

Sell Bills to Odoo / recorded walkthrough

System flow

  1. List spreadsheet tabs and extract their names
  2. Loop through each tab and read its bill rows
  3. Normalize fields before querying Odoo
  4. Fetch matching records and product attribute values
  5. Apply JavaScript rules, filters, merges, and conditions
  6. Create the final Odoo sales-order records

What this proves

  • Large multi-stage workflow visible in one recorded walkthrough
  • Uses branching and filtering to prevent uncontrolled record creation
  • A real Odoo sales order was verified in the supplied proof
  • Customer-identifying output and the raw workflow export are intentionally kept out of the public site
