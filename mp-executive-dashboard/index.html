Executive reporting / published

MP Executive Dashboard

A webhook-driven reporting system that discovers visible Google Sheets tabs, reads their values, combines the datasets, computes executive metrics, builds a complete HTML dashboard, and returns it immediately to the requester.

  • n8n
  • Google Sheets API
  • Webhook
  • JavaScript
  • HTML
MP Executive Dashboard / recorded walkthrough

System flow

  1. Receive a browser request through the production webhook
  2. List and filter the visible main Google Sheets tabs
  3. Read tab values and merge the retrieved datasets
  4. Compute dashboard metrics in JavaScript
  5. Build the HTML interface and respond through the webhook

What this proves

  • Published end-to-end webhook workflow
  • Dynamic discovery avoids hard-coding every spreadsheet tab
  • Business logic and presentation are generated inside the automation
